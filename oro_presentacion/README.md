# Predicción de recuperación de oro
**Daniel Rodríguez | Ingeniería y Ciencia de Datos**

Proyecto académico de TripleTen que explora el uso de modelos de regresión para estimar la recuperación de oro en las etapas de flotación y del proceso final.

## Competencias aplicadas
- Exploración de datos de procesos industriales con Python y Pandas.
- Análisis de concentraciones de metales y características de alimentación.
- Comparación de regresión lineal, árboles de decisión y bosques aleatorios.
- Evaluación con sMAPE ponderado y validación temporal.
- Preparación de datos mediante pipelines para reducir el riesgo de fuga de información.

## Enfoque de negocio
Relacionar las variables del proceso con la recuperación de oro y comparar la capacidad predictiva de distintos modelos como ejercicio de apoyo al análisis industrial.
