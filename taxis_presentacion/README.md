# Predicción de demanda de taxis por hora
**Daniel Rodríguez | Ciencia de Datos y Analítica Predictiva**

Proyecto académico de TripleTen que explora el uso de series temporales y modelos de regresión para pronosticar el número de pedidos de taxi de la siguiente hora.

## Competencias aplicadas
- Preparación y agregación horaria de datos con Python y Pandas.
- Exploración de patrones de demanda y estacionalidad.
- Construcción de retardos y medias móviles con información pasada.
- Comparación de modelos de regresión y referencias temporales simples.
- Evaluación cronológica mediante RMSE, MAE y R².

## Enfoque de negocio
Anticipar variaciones de demanda como ejercicio de apoyo a la planificación de disponibilidad de taxis, conectando el análisis temporal con una necesidad operativa.
