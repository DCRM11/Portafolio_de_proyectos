# Selección de regiones para perforación de pozos
**Daniel Rodríguez | Ingeniería de Petróleos y Ciencia de Datos**

Proyecto académico de TripleTen que explora cómo utilizar modelos predictivos y análisis estadístico para comparar regiones petroleras y apoyar la selección de pozos.

## Competencias aplicadas
- Exploración y validación de datos con Python y Pandas.
- Predicción de volúmenes mediante regresión lineal.
- Evaluación del modelo con RMSE.
- Selección de pozos y análisis de incertidumbre mediante bootstrap.

## Enfoque de negocio
Integrar la calidad de las predicciones con los supuestos económicos del ejercicio para comparar beneficio potencial y riesgo.
